## 安装

适配本机 Slay the Spire 2 0.111.0、RitsuLib 0.6.7、Godot 4.5.1。

退出游戏，将发布包里的 `mods/Frostsworn` 替换旧模组目录。框架 `mods/STS2-RitsuLib` 需保持完整目录结构。不要同时保留两个相同 ID 的霜誓者版本。

本版删除了多张卡与状态，旧进行中存档不作为兼容保证，请新开一局。发布包不会自动覆盖游戏目录或存档。

本机游戏路径为 `C:/fz/steam/steamapps/common/Slay the Spire 2`。

## 内容

卡牌总览按攻击、技能、能力分类，再按寒霜、冰晶、自霜、冰甲、冷藏、解冻、雪势和通用分组。跨体系的牌有索引，括号内为升级后数值。

静雪冥想使用原版 EnergyNextTurnPower，新增独立的下回合冰甲状态。冻结心愿使用独立的下回合额外解冻状态。祝福之风让敏捷应用于冰甲，铭刻于心让力量应用于雪势；该应用规则不因重复打出而翻倍，获得的敏捷／力量可正常叠加。

晶莹生成带原生附魔模型「锐利」的冰晶，升级后生成冰晶+。春汛走原版自动出牌流程，正确触发出牌、附魔、消耗及能力等流程；仅处理开始结算时冷藏区的牌，不把结算途中新冷藏的牌无限加入同次处理。

冷藏容量仍为基础 4、最高 10。同一实体牌每回合可以多次冷藏与解冻；费用优惠仍仅限下一次打出且不叠加。

## 修改卡牌与构建

所有牌的名称、描述和数值现在统一在 `tools/cards_data.py`，状态文本在 `tools/powers_data.py`。不要编辑生成的 `Source/ExpansionCards.cs`。实际卡牌结算在 `Source/RevisedEffects.cs`，升级逻辑在 `Source/Cards.cs`，冷藏逻辑在 `Source/ColdStorage.cs`。

参照「自己改卡说明.md」。在当前工作区运行 `rebuild-local.ps1` 可生成代码、本地化、DLL 和 PCK；它使用本机已准备的编译依赖，不自动安装到游戏。`Tests/build-tests.ps1` 与 `Tests/run-tests.ps1` 运行当前版本测试，旧版测试留在 `Tests/Legacy052` 作为历史参考，不再参与当前编译。

仅下载源码到其他位置时，需要 .NET 9 或更新 SDK、Python 3 与 Pillow、Godot 4.5.1，以及本机合法安装的游戏文件。可用 `dotnet build Frostsworn.csproj -c Release -p:GamePath="游戏路径"` 恢复固定的 RitsuLib 0.6.7 依赖并构建 DLL；资源使用 Assets 下的 pack.gd 打包。源码包不包含游戏 DLL、GodotSharp 或 Harmony 等原版依赖。
