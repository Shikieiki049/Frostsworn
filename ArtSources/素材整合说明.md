# 0.7.5 美术资源整合

素材来源：用户提供的《角色素材.zip》。运行时资源位于 Assets/Frostsworn/art075，独立于占位图生成器，重新构建不会覆盖。

- 战斗立绘1 → battle.png：战斗、商店与营地静态形象。
- 选角背景 → selection.png；缩略图 → portrait.png；地图标记 → map.png。
- 能量图标 → energy.png：卡牌费用、正文能量图标与战斗能量面板。
- 打击、防御、冻结射线 → FrostStrike/FrostDefend/FreezeRay.png，保留原图背景。
- 遗物合图 → relics.png，两个 AtlasTexture 分别用于封冬之核、至冬核心。
- 药水合图 → potions.png，三个 AtlasTexture 分别用于冰冰药水、液氮、分形雪花。
- 附魔-锐利 → sharp.png；设定图留在本目录作参考。

卡框复用原版 HSV shader，h=0.62、s=2.37、v=2.62；角色名称与牌组色 #7694DF。原版 HSV 是对卡框底图的调色参数，不能保证卡框每个像素等于该十六进制颜色。

抠图使用内置 imagegen 编辑，提示：Remove ONLY the plain background and make it genuinely transparent with an alpha channel. Keep every foreground object, original colors, outlines, fine details, silhouette, orientation, composition and relative position unchanged. No redraw, no added objects, no text, no shadow, no checkerboard pixels. Preserve the original canvas aspect ratio and include all foreground objects fully without cropping. Output a clean transparent PNG for use in a game.
