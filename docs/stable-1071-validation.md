# 正式版 0.107.1 适配与历史回归

验证日期：2026-10-19。候选模组：0.9.9。游戏：0.107.1（59260271）。前置：RitsuLib 0.6.7 的 0.107.1 兼容组件。独立 Godot 4.5.1 Mono 测试宿主加载本机游戏程序集、游戏 PCK 与模组发布 PCK，使用 FrostswornHarness 隔离档案。

最终结果：**26 组通过，5802 项断言通过，引擎 ERROR 为 0**。额外执行了 4 组带渲染的截图检查。

## 改动

- 正式版采用五参数伤害修正回调、从卡牌读取出牌玩家、单参数 FromCard，以及返回 Task 的消耗命令。保留多段藏刃加伤、晶锋穿透和冰晶真实消耗登记。
- 卡图刷新补丁针对正式版的 UpdateVisuals。正式版没有测试版的部分冰霜球、玻璃球特效场景，改用该版原生粒子组件和小冰盾，保持原有冰晶飞行与法阵。
- 正式版保留原生 RNG 计数器同步和原生模型 hash，不编入仅适用于 0.111.0 的 FSR1 状态同步与 hash 补丁。
- 构建明确识别目标版本，命令行路径参数优先于本地配置；产物附带实际目标版本，两个目标分别编译。

## 验证边界

这是本地游戏引擎模拟与原生组件渲染回归，不是人工完整通关，也不是两台电脑真实 Steam 联机。仍需实测：多角色模组并存时从大厅开局、SL 后进怪物房、换幕和换房的两端网络时序；不同辅助/皮肤模组组合；长时间游玩、断网重连与真实存档迁移。编码宽度测试保持双方位宽和 ID 表一致，没有声称支持两端不同角色内容或不同版本。

正式版原生网络写入不接受 null 种子；测试确认该非法输入被拒绝，正常局使用具体种子。未修改游戏本身的空种子行为。测试程序使用的临时先古对话节点已明确释放，避免退出时产生字体句柄泄漏误报。

0.111.0 当前不在本机，未用其程序集重新编译本次改动；旧版分支代码保留，但不把条件代码审阅算作本次测试版验证。工坊现已通过 Steam 多版本机制保留 0.9.8（public-beta），发布 0.9.9（public）；已从 Steam API 读回两个独立范围并核对公开改动说明。不能把正式版 DLL 直接覆盖给测试版玩家。
