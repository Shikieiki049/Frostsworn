# 卡牌特效设计

仅添加战斗表现。打击、防御、不可打出的耗尽保留原状。原版抽牌、格挡、回血、消耗牌动画照常播放。

攻击特效接入原版 AttackCommand 的命中回调，多段攻击逐次播放，群体牌定位到各敌人。技能和能力牌在出牌时表现凝结、封存、解封或聚能。所有动画在本机播放，不使用战斗随机数，不增加出牌等待，不参与存档或网络结算。

使用原版冰霜充能球的雪与护盾、玻璃充能球冲击、通用冰屑、光环、云雾和斩击粒子；冰晶使用原版 frost_orb_particle 纹理；寒光束用原生 Line2D 定位施法者到敌人，再拼接原版命中闪光与寒雾。粒子材质单独复制，避免影响原版效果。尺寸限制在角色周围，雪崩和绝对零度稍强，常用冰晶较轻。
