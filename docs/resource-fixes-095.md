# 0.9.5：错误报告修复与范围

- 日食图标：0.9.4 的 EclipseUi.Icon 在纹理加载失败时直接调用 GetImage，导致选择界面和计时刷新空引用。现在检查纹理、图像和有效裁剪区域，异常资源显示备用日食环；缓存备用结果，失效缓存重新加载。所有正常等级继续使用原图。
- 可选原版特效：针对报告中的 Handle is not initialized 以及已释放对象异常，在加载/实例化边界安全跳过可选场景。未初始化句柄的底层来源尚未复现，本版是异常隔离，不宣称消除了 Godot 的根因；其他 InvalidOperationException 仍然抛出。
- 打包：目录打不开或任一文件添加失败立即返回失败，禁止把部分资源包当作成功构建。

## 验证

原版 Godot + sts2.dll + RitsuLib 引擎测试：缺失/透明空图/已释放的日食图标；0—8 级原图加载、裁剪与缓存；模拟句柄异常、错误类型及已释放特效；正常特效保留且无关编程错误不被吞掉。对实际 PCK 中全部 531 个 PNG/SVG/AtlasTexture 进行加载和解码；通过全部 90 个非基础卡牌特效、飞行/命中/清理，以及原版场景缺失的回退测试。

## 尚未确认

日志中多种图片同时加载/解析失败，本地发布包未复现。不能仅凭这些日志认定漏打包或玩家文件损坏。冰晶/打击的 Canceled 动作报告也不足以确定根因。本次不修改牌效、日食规则、随机数或联机协议。
