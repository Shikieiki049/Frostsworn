# 0.9.15 正式版兼容与错误报告复核

新增 1,874 份报告全部读取。六份异常来自 Gambler 的花色预览对霜誓者卡牌模板读取 Owner。兼容补丁只跳过该查询方法对霜誓者只读模板的处理。测试夹具复现原生 Owner 异常并通过 Harmony 实际调用验证；Gambler 工坊 DLL 尚未联测。

另外两份 Spine 空引用和三份 RitsuLib 攻击链异常在进入霜誓者的怪物动作观察器前已经发生。八份联机分歧报告中有四份记录同一组选牌编号差一，现有日志无法确定产生额外选择的效果。

正式版目标为游戏 0.111.0。RitsuLib 0.6.10 和 0.6.12 各运行五组引擎测试，合计 404 条断言通过，覆盖 Gambler 预览、记忆蜕片、虚空遗物、网络封包及版本警告。使用真实 0.111.0 游戏程序集与资源。

测试版使用游戏 0.113.0 与 RitsuLib 0.6.12 对应程序集，适配遗物可用性、灯塔水母最大生命值扣减和数值预览。六组引擎测试共 252 条断言通过。

2026-11-14 工坊已发布两套 0.9.15 内容，正式版 public（0.111.0）和测试版 public-beta（0.113.0）的双语改动说明及分支关联均可查。测试版订阅文件哈希匹配：False。正式版订阅下载未复测。
